# multi-tool-alpha-pc - PC version
Only for your own lab / authorized targets.

Everything you do is your own risk.

## Arch
sudo pacman -S --needed python git
git clone https://github.com/Dr-maynard/multi-tool-alpha-pc.git
cd multi-tool-alpha-pc
python3 main.py

## Debian / Kali
sudo apt update && sudo apt install -y python3 git
git clone https://github.com/Dr-maynard/multi-tool-alpha-pc.git
cd multi-tool-alpha-pc
python3 main.py
